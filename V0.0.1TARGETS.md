# v0.0.1 targets

The first demo. The goal is that someone who knows OctaMED Pro V4 can sit down, make a short song
from samples start to finish, save it, and open it again later, here or in the real OctaMED.

Anything not listed stays ghosted in the GUI for now.

## Must have

### Songs
- [x] Load MMD0 and MMD1 modules, notes, instruments and metadata
- [x] Save songs as MMD1 with instruments (SAVE SONG), loadable by the real OctaMED
    - [x] Writing MMD modules (round-trips parsed modules, used by the CLI's `rewrite`)
    - [x] Turning a project back into a module
    - [x] Hooking up SAVE SONG
- [x] Clear song / clear all, quit with a check for unsaved changes

### Playback
- [x] Play song and block, continue song and block, with the tempo and the 4 channels
- [ ] The volume command (0C), as a trial run for the rest
- [x] Filter on/off

### Editing
- [ ] Block editor
    - [x] Notes, instruments and command digits
    - [x] Holds, highlights and octaves
    - [x] Deleting and inserting notes, spaces and tracks (Del, Backspace and their Shift and Alt
          versions)
    - [ ] Selection ranges
    - [ ] Cut, copy and paste
        - [x] Tracks and blocks: the BLOCK panel's TRK:/BLK: CUT, COPY, PASTE, SWAP and DEL BUFF,
              and Amiga-x/c/v, Amiga-X/C/V. The exact behaviour still needs checking against the
              real OctaMED: separate track and block buffers, what PASTE and SWAP do when the
              buffer and the track or block differ in length, and whether a block PASTE takes on
              the buffer's size
        - [ ] Selection ranges (and whether they share the track or block buffer)
    - [x] Create a new block (the BLOCK panel's NEW BLOCK, NEW HERE and their DEFs)
    - [x] The rest of the BLOCK panel: LINES, EXPAND/SHRINK, INS/DEL line and track, highlight
          spacing, DELETE LAST/THIS, SPLIT and JOIN
- [x] Sequence editing
    - [x] Insert and delete entries
    - [x] Change the block at an entry
- [ ] Undo for the block editor

### Instruments
- [x] Load WAV, MP3, FLAC, IFF and raw samples
- [x] Sample editor: ranges, zoom, cut/copy/paste, clear, reverse, mix, freehand, play range and
      display, BUFFSIZE
- [x] Save instruments as raw, IFF or WAV
- [x] Instrument settings
    - [x] Volume, transpose and finetune
    - [x] Hold and decay, with -|- hold symbols (not command 08 yet)

### Release
- [ ] Builds for Windows, Linux and Mac on the releases page
    - [x] Release workflow
    - [ ] A published release
- [ ] A short addendum listing what's different from the original

## Nice to have

- [x] Render the song to WAV
    - [x] From the command line (`mmd_cli record`)
    - [x] From the GUI
- [ ] PAL/NTSC and memory as settings
    - [x] PAL/NTSC toggle (Ctrl+F12, temporary)
    - [ ] As settings, with memory
- [x] A play position line in the sample editor

## Not in the demo

- Sample commands other than volume
- Synth and hybrid sounds
- More than 4 tracks (the BLOCK panel's 8/12/16): the engine only plays 4 channels, with no split
  channel mode or MIDI to use the rest
- MIDI in and out, audio interface routing
- Keybind remapping, configuration overrides
- Loading ProTracker and SoundTracker modules
- MMD0 and MMD1 without instruments as save formats

## Known issues
