# V0.01 targets

The first demo. The goal is that someone who knows OctaMED Pro V4 can sit down, make a short song
from samples start to finish, save it, and open it again later, here or in the real OctaMED.

Anything not listed stays ghosted in the GUI for now.

## Must have

### Songs
- [x] Load MMD0 and MMD1 modules, notes, instruments and metadata
- [ ] Save songs as MMD1 with instruments (SAVE SONG), loadable by the real OctaMED
- [ ] Clear song / clear all, quit with a check for unsaved changes

### Playback
- [x] Play song and block, continue song and block, with the tempo and the 4 channels
- [ ] The volume command (0C), as a trial run for the rest
- [x] Filter on/off

### Editing
- [ ] Block editor: notes, instruments, commands, holds, ranges, cut/copy/paste
- [ ] Sequence editing: add, remove and reorder blocks in the play sequence
- [ ] Undo for the block editor

### Instruments
- [x] Load WAV, MP3, FLAC, IFF and raw samples
- [ ] Sample editor: ranges, zoom, cut/copy/paste, clear, reverse, mix, freehand, play range and
      display, BUFFSIZE
- [ ] Save instruments as raw, IFF or WAV
- [ ] Instrument volume, transpose, finetune, hold and decay

### Release
- [ ] Builds for Windows, Linux and Mac on the releases page
- [ ] A short addendum listing what's different from the original

## Nice to have

- [ ] Render the song to WAV
- [ ] PAL/NTSC and memory as settings
- [ ] A play position line in the sample editor

## Not in the demo

- Sample commands other than volume
- Synth and hybrid sounds
- MIDI in and out, audio interface routing
- Keybind remapping, configuration overrides
- Loading ProTracker and SoundTracker modules
- MMD0 and MMD1 without instruments as save formats

## Known issues
